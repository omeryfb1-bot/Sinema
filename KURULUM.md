# Sinema Odası: ücretsiz yayına alma (telefondan da yapılır)

## 1) Kodu GitHub'a koy
1. github.com'da ücretsiz hesap aç, "New repository" de, adı `sinema`.
2. "uploading an existing file" ile bu klasördeki tüm dosyaları yükle
   (`server.js`, `package.json`, `public/` klasörü: `index.html` ve `b.js`).

## 2) Render'da ücretsiz yayına al
1. render.com'a GitHub hesabınla gir.
2. New > Web Service > `sinema` deposunu seç.
3. Ayarlar: Runtime `Node`, Build Command `npm install`, Start Command `npm start`, Plan `Free`.
4. Deploy bitince `https://sinema-xxxx.onrender.com` gibi bir adres verir.

## 3) Telefona ve tablete ekle
1. Adresi Safari'de aç.
2. Paylaş düğmesi > "Ana Ekrana Ekle".
3. Sevgiline aynı adresi gönder, o da ana ekrana eklesin.
4. İkiniz de aynı oda koduyla girin.

## Notlar
- Ücretsiz sunucu uykuya dalar, ilk açılış 30-60 sn sürebilir. İzlemeye başlamadan birkaç dakika önce açın.
- Mikrofon bazen mobil veride bağlanmayabilir (ücretsiz STUN sunucusu kullanılıyor). Wi-Fi'da genelde sorunsuz.
- Mikrofon için Safari'den izin vermeyi unutmayın.
